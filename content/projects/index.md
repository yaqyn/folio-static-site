# Projects

A collection of things I build to learn, solve a problem, or make a tool my own. The source is the best place to see how each one works.

## qvOS

A Linux operating-system project and an ongoing exploration of a personal computing environment.

[Explore qvOS on GitHub](https://github.com/yaqyn/qvOS)

## AI Agent

A command-line coding agent using OpenRouter. It can inspect a project, edit files, and run Python through workspace-scoped tools. Read-only mode, bounded runs, and saved transcripts make its behavior easier to examine.

[Explore AI Agent on GitHub](https://github.com/yaqyn/AI_Agent)

## Web Crawler

An asynchronous website crawler with a fixed worker pool, robots.txt checks, request limits, and structured JSON reports. A practical exercise in concurrency and handling failures without losing the whole run.

[Explore Web Crawler on GitHub](https://github.com/yaqyn/web_crawler)

## Asteroids

A Pygame arcade game. Pilot a wireframe ship, split incoming rocks, and survive with three lives. It includes pause and restart flows, a saved best score, and reduced-motion options.

[Explore Asteroids on GitHub](https://github.com/yaqyn/Asteroids)

## BookBot

A dependency-free text-analysis tool that counts words and letters, ranks vocabulary, compares books, and exports JSON or CSV reports.

[Explore BookBot on GitHub](https://github.com/yaqyn/BookBot)

## RAG Search Engine

A movie search project exploring keyword search, semantic embeddings, hybrid ranking, and reranking. Built while working through the Boot.dev retrieval course.

[Visit my repositories](https://github.com/yaqyn)

## This site

A static site generator written in Python. It turns Markdown into a linked website using a shared template and a small HTML-node model.

[Read how the site works](/notes/static-sites/) or [explore the source](https://github.com/yaqyn/my-site).
