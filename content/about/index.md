## Personal projects

**qvOS** is a standalone Arch Linux distribution in active development, with its own desktop, tools, installer, and release lifecycle. A keyboard-first Hyprland environment supports daily development and automation, while installation, updates, and recovery remain part of the same system. Public ISO downloads are not available yet.

Package foundation: Omarchy’s signed Stable repositories, distributed through Cloudflare, support the focus on stability.

**Counter** is a native Omarchy plugin for quiet counting. It reserves a chosen key, displays the total in the bar, and saves the total and key across restarts. A native panel supplies Reset, Undo, and key selection without interrupting counting.

## From requirements to verification

The starting point is a user task and its handoff: what initiates it, which records change, who acts next, and how failure should be handled. Implementation connects the interface to those rules; review and relevant checks determine what can be claimed about the result.

Local checks, CI, and live verification answer different questions. A successful push does not by itself establish deployed behavior.
