About

I'm Abdulrahman M. Yaqyn, also known as yaqyn. My work spans Python projects, Linux systems, and the tools I use every day.

Learning by building

I work through projects on Boot.dev, turning ideas into code and then examining where that code fails. A book analyzer, a crawler, a game, and a search engine each reveal a different part of the same craft.

The small details matter: an error that explains what happened, a test that catches a real failure, and a command that works from where you actually run it.

A personal computing environment

Linux is part of that work. qvOS and desktop customization let me explore how a system can fit its user, from the underlying software to a keyboard-first workflow.

See the projects for the code, or read the notes for a closer look at the ideas behind it.
